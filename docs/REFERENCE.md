# SubBar — полный справочник

Менюбар-программа для macOS: субагенты Claude Code работают на моделях OpenCode Go,
а основная сессия остаётся на подписке Anthropic. Плюс лимиты подписок, включая **Claude 5ч / неделя**.

## Субагенты Claude на OpenCode Go

Идея: основная сессия Claude Code остаётся на подписке (Opus), а субагенты `haiku` незаметно для неё
работают на модели OpenCode Go. Запускай **`claude-sub`** вместо `claude` — остальное как обычно.

**Экран «Субагенты»** (кнопка **⇄** в шапке; зелёная точка на ней — подмена работает). В шапке — счётчики и с какого
момента они идут («с 23:18 · 36 ответов субагентов»: прокси считает с запуска; откаты и ошибки — только если были), итог
последнего субагента («Работает · последний субагент 3 мин назад»; ушёл в Claude или получил ошибку — янтарная
точка и причина) и главный переключатель **«Подмена»**. Ниже три группы:
- **Модель**: `deepseek-v4.1-flash`, `space-bunny-free`, `muse-spark-1.3-contributor`; **Размышление**: как просит
  Claude / low / high / max (у muse `max` нет — уходит `xhigh`); **«Проверить»** — крошечный запрос через прокси:
  «✓ Отвечает за 1,2 с · OpenCode #4 · «ок»». Проверка идёт сама при открытии экрана (не чаще раза в 10 минут).
- **Ключи OpenCode Go** — весь запас строками: кружок — основной ключ (клик по строке — сделать основным; пока основного
  нет, им сам становится первый добавленный), статус
  («основной · в работе», «запас · следующий» — куда уйдёт ротация, «запас», «пауза · ещё 1д 3ч», «сброс через 1д 3ч»
  у исчерпанного, «карточка выключена»), остаток самого тесного окна с полоской; все окна — в подсказке строки.
  Под списком — **«Кончился лимит — брать следующий ключ»**: исчерпанный ключ уходит на паузу до сброса (срок из
  `Retry-After`), тот же запрос повторяется на ключе с наибольшим запасом; основной возвращается сам.
- **Поведение**: **кого подменять** (субагенты haiku или haiku и sonnet); **OpenCode молчит — откат в Claude**
  (запрос уходит на настоящую модель Claude; мысли с чужими подписями вычищаются — Anthropic их не примет);
  **Прокси как служба** — автозапуск и перезапуск при сбое, рядом журнал (`proxy.log` в «Консоли») и **↻** — мягкий
  перезапуск.

Лимиты Claude на этом экране не дублируются: они в карточке Claude (закрепи её — будет сверху и в менюбаре).

**Как понять, что субагенты сейчас на deepseek, а не на haiku.** Переключатель **«Строка в Claude Code»**
(в «Поведении», или `subbar statusline install|remove`) добавляет вторую строку внизу Claude Code — своя строка
состояния остаётся первой:
- `deepseek-v4.1-flash · 3 аг · 12 отв` — зелёная: эта сессия идёт через прокси, субагенты (3 агента, 12 ответов)
  отвечают моделью OpenCode (прокси считает по id сессии Claude Code); `· пока не запускались` — ещё ни одного;
- `· ключ OpenCode #4` — серым, если ответил не основной ключ; `· 2 в Claude` — янтарным: часть ушла на настоящую
  haiku (платно); `· 1 ош` — красным;
- `подмена выключена · настоящий Claude`, `нет ключа OpenCode · настоящий Claude`;
- `настоящий Claude · не через claude-sub` — запущен обычный `claude`; `настоящий Claude · прокси SubBar не запущен`.
В узком терминале цветные хвосты уходят с конца, модель и счёт остаются.
Строка работает ~0,1 с и не тормозит терминал; копия настроек перед правкой — `~/.claude/settings.json.subbar-backup`.

**Как устроено**
- Прокси `127.0.0.1:8479` (служба `ai.subbar.proxy`). Основная модель — на `api.anthropic.com` байт в байт.
  Запрос haiku (или haiku и sonnet — «Кого подменять») **с инструментами** — в OpenCode Go; служебные вызовы без инструментов не трогаются.
- **OAuth подписки в OpenCode не уходит никогда** (есть сквозной тест): туда идёт только ключ OpenCode.
- deepseek и space-bunny понимают формат Claude напрямую; muse — только OpenAI Responses, для него переводчик
  (инструменты, поток, зашифрованные рассуждения переживают ходы).
- `x-opencode-session` = id сессии Claude Code: кэш промптов OpenCode держится только при постоянном id
  (замер: 12 672 из 12 874 токенов из кэша против 0 при новом id).
- Поток: в тишине — `ping` каждые 10 с (muse на xhigh молчит до 2 минут), после 5 минут тишины — честная
  ошибка, Claude Code повторит; OpenCode не ответил за 60 с — откат.
- Временный сбой OpenCode (500, 502, 503, 504, 408, 520–529, соединение не установлено) — два повтора через 0,5 и 1,5 с,
  и только потом откат. Ошибка самого запроса (400, 413, 422) не повторяется.
- Запрос к DeepSeek подправляется под его правила (все — замеры 27.09, иначе немой 400 `{"model":…}`):
  без `pattern` в схемах инструментов (Artifact шлёт `^[^\0]*$`); ходу с вызовом инструмента без мысли
  подкладывается пустая мысль; при `tool_choice: tool` мысли выключаются.
- Мысли с чужой подписью (deepseek, space-bunny, muse) в Anthropic не уходят — ни на откате, ни когда сессию,
  шедшую через OpenCode, продолжили на модели Claude. Подписи Claude узнаются по устройству: `CAQS…`/`CAIS…`
  (конверт), `E…`, двойной слой `R…`; обычная сессия Claude уходит байт в байт.
- SIGTERM (перезапуск, установка новой версии): прокси доделывает начатые запросы (до 50 с) и только потом
  выходит — субагенты посреди ответа не обрываются.
- Настройки подхватываются на лету; статус — `http://127.0.0.1:8479/_subbar/status`,
  журнал — `~/Library/Logs/SubBar/proxy.log`.

**Основной модели** `claude-sub` добавляет подсказку: субагенты `haiku` в этой сессии — воркеры OpenCode, объёмную
рутину отдавай им. Если в «Кого подменять» выбрано «haiku и sonnet» — подсказка называет обе модели (`sonnet` для
задач посложнее), иначе прямо говорит, что `sonnet` тратит подписку. Подмена идёт по модели, а не по роли: основная
сессия на haiku/sonnet тоже уходит в OpenCode — так задумано (тогда подсказки нет, она бы соврала).
Попросишь «раздай субагентам» — она возьмёт `model: haiku` (или `sonnet`), и работа уйдёт в OpenCode
(отключить: `SUBBAR_HINT=0 claude-sub`; своим `--append-system-prompt` подсказка не мешает).

**Безопасность**: прокси слушает только `127.0.0.1`; запросы из браузера (заголовки `Origin`/`Sec-Fetch-*`) и на
чужие имена хоста (DNS rebinding) получают 403 — иначе любая открытая страница могла бы тратить квоту OpenCode.
Ключи в журнале, статусе и уведомлениях — только маской.

**Терминал**
```bash
claude-sub                               # Claude Code через прокси (прокси не отвечает — обычный claude)
subbar proxy-check                       # ✓ deepseek-v4.1-flash отвечает · ключ OpenCode #4 · 1261 мс · «ок»
subbar proxy-config                      # показать настройки (ключ замаскирован)
subbar proxy-config model=muse-spark-1.3-contributor effort=max rotate=true
subbar proxy-service on|off|restart      # служба прокси; restart — мягкий
```
Здесь — полный справочник: все экраны, настройки, CLI и внутреннее устройство.

## Установка

Готовое приложение из последнего релиза (macOS 13+, Apple Silicon и Intel), без Rust и Xcode:

```bash
curl -fsSL https://raw.githubusercontent.com/Lutamona/SubBar/main/scripts/get.sh | bash
```

`get.sh` скачивает `SubBar.zip` и `install.sh` той же версии, сверяет SHA-256 и зовёт `install.sh --app`. Обновление —
та же строка. Скачал архив руками — `./scripts/install.sh --app путь/SubBar.app` из клона репозитория.

Из исходников нужны Command Line Tools (`xcode-select --install`) и Rust/Cargo:

```bash
./scripts/make-app.sh          # соберёт dist/SubBar.app (--universal — Apple Silicon + Intel одним бинарём)
./scripts/install.sh           # соберёт и поставит в /Applications
```

`install.sh` перезапустит окно, мягко перезапустит службу прокси (начатые запросы доделает) и проверит, что отвечает
новая версия; `~/.local/bin` нет в PATH — допишет его в `~/.zshrc` (у bash — в `~/.bash_profile`).
При первом запуске SubBar сам добавляет карточку Claude (из входа Claude Code). Первая карточка OpenCode Go сама
становится основным ключом субагентов, а заодно встаёт служба прокси — если её не выключали руками: переключатель
«Прокси как служба» и `proxy-service off` оставляют метку `.proxy-service-off` рядом с `proxy.json`, включение её снимает.

Релиз (нужен `gh` с правом записи): подними `version` в `Cargo.toml`, закоммить и запусти `./scripts/release.sh` —
универсальная сборка, `SubBar.zip` с контрольной суммой, тег `v<версия>` и релиз на GitHub.

В менюбаре — по кольцу на каждое окно лимита (до трёх, в том же порядке, что в карточке: 5ч, 7д, 30д): дуга —
доля, число внутри — остаток (или расход) в процентах. Показывается **верхний из закреплённых** аккаунтов, а если
закреплённых нет — самый израсходованный. Подсказка при наведении расшифровывает кольца («5ч 100% · 7д 41% · 30д 21%»), пишет срок
сброса самого тесного окна и идут ли субагенты в OpenCode. Значок ~80 пт: длинная строка «5ч 100% 7д 41% 30д 21%»
на Mac с вырезом экрана пряталась. Выключишь «Числа в кольцах строки меню» — останутся кольца без чисел. Клик открывает список.

## Как добавить подписки

1. Клик по значку в менюбаре → **+** в шапке окна (или клавиша **+**). Форма сразу открывается на сервисе, которого
   у тебя больше всего карточек, а пустое название продолжит твою нумерацию («OpenCode #6» → «OpenCode #7») — оно
   видно в поле заранее.
2. Выбери сервис, заполни поля (или нажми **«Найти на этом Mac»** — приложение само найдёт
   сохранённые входы у CLI: `$CODEX_HOME/auth.json` (по умолчанию `~/.codex`), `auth.json` OpenCode
   (`~/.local/share/opencode`, `~/Library/Application Support/opencode`, `~/.config/opencode` — в этом порядке),
   `~/.commandcode/auth.json`, локальный CLI/кэш Devin, Keychain Claude).
3. **Добавить**. У длинной формы своего JSON API прокручивается только список полей: заголовок и кнопки остаются на месте. При переключении сервиса введённые поля сохраняются как черновики до закрытия формы и не переносятся в другой сервис.

Сколько ключей на один сервис — столько карточек. Например, 10 разных ключей OpenCode Go
добавляются как 10 подписок, каждая со своим названием («OpenCode #1», «OpenCode #2»…).

В шапке — число аккаунтов, строка состояния («3 на исходе · 1 без свежих данных» или «Обновлено только что») и четыре
кнопки-иконки с подсказками: добавить (**+**), обновить (**R**), субагенты (**⇄**, зелёная точка — подмена работает),
настройки (**,**). Поиска нет. Окно со списком растёт до 760 пт, если экран позволяет, — прокрутки меньше.

Карточка: крупный процент — самое тесное окно (подписано под ним: «осталось · 30д»), под названием — **когда лимит
вернётся** («сброс через 1д 4ч»; у Claude ещё и план: «Pro · сброс через 4ч 27м»). Ошибка или несвежие данные —
янтарным. Красная рамка и полоска — низкий остаток. **Булавка** — закреплена, зелёная метка
**«субагенты»** — на этом ключе сейчас работают субагенты (клик по ней открывает экран «Субагенты»).

**Закреплённые** (меню **···** или правый клик → «Закрепить наверху») стоят сверху в твоём порядке: «Поднять выше» /
«Опустить ниже» в том же меню; верхняя из них — в менюбаре. Новая закреплённая встаёт последней среди закреплённых.
Остальные карточки идут сами — самые израсходованные выше.

Внизу карточки — до трёх окон; самое тесное всегда в сводке. Клик раскрывает все окна: подпись, срок сброса и значение
строкой, полоса во всю ширину — как лимиты Claude на экране «Субагенты». Кнопка **···** (подсвечивается при наведении)
открывает действия аккаунта, правый клик работает в любом месте карточки. У OpenCode Go и Command Code там есть
**«Скопировать API key»**. **«Удалить»** (в меню и в форме правки) удаляет сразу, но 15 секунд карточку вместе с
ключом можно вернуть — **«Вернуть»** в шапке или **⌘Z**. У булавки и метки «субагенты» есть подсказки при наведении.
Список прокручивается колёсиком, стрелками и Page Up/Down.

## Что откуда берётся

| Сервис | Источник данных | Что показывает |
| --- | --- | --- |
| ChatGPT / Codex | `chatgpt.com/backend-api/wham/usage` с токеном из `~/.codex/auth.json` (или введённым вручную); токен живёт ~10 дней — Codex CLI обновляет его в `auth.json`, и карточка сама берёт свежий токен того же аккаунта (auth.json SubBar только читает) | основные и дополнительные окна лимитов, тариф, сбросы |
| OpenCode Go | `opencode.ai/zen/go/v1/usage` с API-ключом | окна 5ч / 7д / 30д |
| Command Code | `api.commandcode.ai/alpha/billing/credits` с ключом из `~/.commandcode/auth.json` | 5-часовое и недельное окно (когда активны), кредиты, лимиты организации (если аккаунт в ней) |
| Devin | кэш `GetUserStatus` от CLI (`~/.cache/devin/cli/user_status.*.bin`), обновляется запуском `devin list` | дневная и недельная квота + время сброса |
| Claude | `api.anthropic.com/api/oauth/usage` с токеном из Keychain «Claude Code-credentials» | окно 5ч, 7д, Fable 7д; токен обновляется сам |
| Своя подписка | любой JSON-эндпоинт | одно окно, пути к полям задаются в форме |

## Настройки

- автообновление: выключено / 1 / 5 / 10 / 30 / 60 минут (по умолчанию 5);
- показывать «осталось» или «использовано»;
- числа в кольцах менюбара (подсказка под переключателем говорит, чья карточка сейчас в кольцах);
- запуск при входе в систему (LaunchAgent `ai.subbar.plist`);
- уведомления при достижении порога (по умолчанию 90%) — только о новых пересечениях: после перезапуска
  SubBar не повторяет уведомления о том, что было за порогом и раньше.

## Где лежат данные

```
~/Library/Application Support/SubBar/state.json   # подписки и настройки (chmod 600)
~/Library/Application Support/SubBar/proxy.json   # настройки прокси: ключ OpenCode, модель… (chmod 600)
```

Креды хранятся там же, в открытом виде — как и в самих CLI. Файл читается только владельцем.

## CLI для отладки

```bash
./target/release/subbar accounts          # что добавлено
./target/release/subbar usage             # обновить и напечатать лимиты
./target/release/subbar detect --import   # найти и добавить подписки
./target/release/subbar add opencode-go "OpenCode #1" apiKey=sk-...
./target/release/subbar remove "OpenCode #1"
./target/release/subbar link-claude "Claude"  # привязать старый импорт к Keychain
```

Для настоящего ключа лучше использовать форму приложения: аргумент `apiKey=...` остаётся
в истории команд и виден другим процессам во время запуска CLI.

Новые аккаунты, найденные через Claude Code, берут актуальный токен из Keychain, даже если он
обновился в самом Claude Code. Для аккаунта, импортированного до этой версии, привязку можно
включить командой `link-claude <id|имя>`; вручную введённые токены без этой команды не
подменяются. Если изменить токен в форме, привязка отключится.

Полезные переменные: `SUBBAR_DATA_DIR` (другой каталог состояния), `SUBBAR_SCREEN=form|settings|proxy`,
`SUBBAR_OPEN_ON_START=1` (сразу открыть попап — удобно для скриншотов), `SUBBAR_NO_REFRESH=1` (не опрашивать
сервисы при запуске — снимки на подставных данных), `SUBBAR_PROXY_CONFIG` (другой `proxy.json`),
`CLAUDE_CONFIG_DIR` (где искать `settings.json` Claude Code), `CODEX_HOME` (каталог Codex). Для тестов прокси:
`SUBBAR_HEADERS_MS`, `SUBBAR_PING_MS`, `SUBBAR_SILENCE_MS`, `SUBBAR_RETRY_MS`, `SUBBAR_DRAIN_MS` (тайминги),
`SUBBAR_ALLOW_PORT0`, `SUBBAR_TPS`.

Проверка живых экранов (только отладочная сборка): `SUBBAR_NATIVE_SELF_TEST=form|list` вместе с
`SUBBAR_OPEN_ON_START=1` открывает попап, прогоняет жизненный цикл формы или списка и выходит с
«native … lifecycle: PASS» (код 0) или FAIL. Работает только на своём каталоге данных вида
`$TMPDIR/subbar-native-selftest.XXXX` (`SUBBAR_DATA_DIR`) — на настоящих данных откажется.

## Живые тесты подмены

`tests/live/live.py` — настоящие запросы в OpenCode Go и настоящий Claude Code через **отдельный** экземпляр прокси
(свой порт и конфиг; твоя служба и настройки не трогаются, ключ — из карточек с наибольшим запасом, в вывод не попадает).

```bash
cargo build --release
python3 tests/live/live.py api      # протокол по каждой модели: поток, инструменты, круг с tool_result, параллельные
                                    # вызовы, размышления и 2-й ход, max_tokens, юникод, 1–400, большой контекст, кэш,
                                    # картинка, stop_sequences, cache_control
python3 tests/live/live.py route    # основная модель / sonnet / haiku без инструментов — не в OpenCode; OAuth не уходит;
                                    # браузер — 403; OpenCode лежит — откат; негодный ключ — ротация; 8 потоков разом
python3 tests/live/live.py agent    # настоящий Claude Code (основная haiku → модель OpenCode): 17 задач с проверкой
                                    # по файлам и ответу — чтение, grep, bash, запись, правка, рефакторинг, юникод,
                                    # большой лог, CSV, субагенты (1 и 3 параллельно)
python3 tests/live/live.py hard     # качество: починить баг до зелёного теста, хитрый код, аналитика CSV, пакет
                                    # с unittest, огромный вывод инструмента, рефакторинг руками субагента, задачи
python3 tests/live/live.py robust   # на живом Claude Code: негодный ключ посреди работы, OpenCode лежит, 6 сессий разом
python3 tests/live/live.py all --models deepseek,bunny,muse,haiku --repeat 2 --opus
```
`--models haiku` — настоящая haiku без подмены (для сравнения; только в `agent` и `hard`), `--opus` — сценарий
«основная Opus + субагенты» (тратит подписку), `--repeat N` — повторы для оценки стабильности, `--only имя` — одна
задача, `--lanes N` — параллельных прогонов Claude Code на модель (по умолчанию 2). Для задачи с картинкой нужен
Pillow (`pip3 install pillow`).

## Известные ограничения

- Command Code: если на аккаунте нет активных окон лимитов, карточка покажет «Лимиты Command Code пока не активны».
- Devin: данные берутся из кэша CLI, поэтому раз в 30 минут приложение просит CLI обновиться (`devin list`).
- Токены Codex/Claude приложение не продлевает само, кроме Claude (там OAuth-refresh).
  Если токен Codex истёк — запусти `codex login`.

- История приводится к правилам OpenCode: `redacted_thinking` и сообщения с пустым массивом `content` выкидываются, `tool_result` идут первыми, у схемы инструмента без `type` появляется `object`.
